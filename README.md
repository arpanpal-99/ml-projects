# Machine Learning Projects

This repository is a growing collection of projects based on the machine-learning
algorithms and techniques I study. It may contain one or more independent projects,
each exploring an algorithm, applying it to data, or building an application around
it.

Projects live in their own folders so they can have separate code, datasets,
dependencies, documentation, and setup instructions. For example:

```text
projects/
├── README.md
├── .gitignore                 # Optional rules that apply across the repository
├── CineMatch/
│   ├── README.md
│   ├── .gitignore             # Rules for CineMatch and its files
│   └── ...
└── another-ml-project/
    ├── README.md
    ├── .gitignore
    └── ...
```

See each project's README for its purpose, requirements, data instructions, and
steps to run it. Do not commit credentials, private data, or generated files that
should be recreated locally.
